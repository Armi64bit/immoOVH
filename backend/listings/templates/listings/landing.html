Comment ça marche ?

  1. Ajouter un bien : cliquez sur « Ajouter un bien », remplissez le formulaire (le plus important : titre, prix, localisation et photo).
  2. Publier : le bien est publié sur le site par défaut. Décochez « Publié » pour le masquer temporairement.
  3. Modifier / supprimer : depuis la liste des biens, utilisez les boutons Modifier ou Supprimer.
  4. API : pour les développeurs, la documentation de l'API se trouve dans « Documentation API ».
